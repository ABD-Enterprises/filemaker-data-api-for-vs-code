# Getting help

For bugs in FileMaker Data API Tools, open a [GitHub issue](https://github.com/SureForgeTech/filemaker-data-api-for-vs-code/issues). For usage questions, use the [Marketplace Q&A](https://marketplace.visualstudio.com/items?itemName=SureForgeTech.filemaker-data-api-tools&ssr=false#qna).

These guides may help:

- [User Guide](extension/docs/USER_GUIDE.md)
- [FileMaker failure modes](docs/FILEMAKER_FAILURE_MODES.md)
- [Upgrade notes](extension/UPGRADE.md)
- [Rollback instructions](docs/ROLLBACK.md)

## Reporting a bug

Include:

- The extension version from **FileMaker: About / Show Version** (use **Copy for bug report**).
- Your VS Code version and operating system.
- Your FileMaker Server or FileMaker Cloud version.
- Steps to reproduce the problem, what you expected, and what happened.
- Output from **FileMaker: Show Diagnostics**, with secrets and private information removed.

Review anything you share, including logs and screenshots. Never paste passwords, session tokens, API keys or other secrets into an issue or Q&A post.

## Security reports

Do not post details of a suspected security vulnerability in a public issue or Q&A. Use the private reporting channel in [SECURITY.md](SECURITY.md).

## What to expect

General support is best effort. There is no support SLA or guaranteed response or fix time. The separate security reporting process and its response expectations are in [SECURITY.md](SECURITY.md).
